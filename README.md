# 🏧 Caixa Eletrônico em Python

Projeto de estudo desenvolvido em Python: um caixa eletrônico simples que roda no terminal, com menu interativo para consultar saldo, depositar, sacar e simular rendimento.

## 📋 Funcionalidades

- **Ver saldo:** mostra o saldo atual do usuário
- **Depositar:** adiciona um valor ao saldo (aceita apenas valores positivos)
- **Sacar:** retira um valor do saldo, com verificação de saldo insuficiente
- **Simular rendimento:** calcula quanto um valor rende com base na taxa (%) e no número de meses (juros simples)
- **Sair:** encerra o programa

## 🧠 Conceitos praticados

- Variáveis e tipos de dados (`int`, `float`, `str`)
- Entrada de dados com `input()` e conversão de tipos
- Estrutura condicional: `if`, `elif`, `else`
- Laço de repetição: `while`
- Formatação de texto com f-strings (`{saldo:.2f}`)
- Validação de entradas do usuário

## ▶️ Como executar

1. Instale o [Python 3](https://www.python.org/downloads/)
2. Baixe o arquivo `caixa_eletronico.py`
3. No terminal, execute:

```bash
python caixa_eletronico.py
```
